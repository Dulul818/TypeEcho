本机隔离浏览器按键测试 30 次，中位数 6.4ms、P95 13ms；12 次延迟换词 / 退格切换及后台整局文本读取时的独立输入均通过。此结果只反映测试环境中的输入回传，不代表模型生成或所有机器的响应时间。

真实 GPT-SoVITS 短词生成约 0.46–0.65 秒，音频 0.47–0.55 秒，两个短句生成约 0.64 / 0.94 秒。原 0.4.18 的静音对照确认 7 个词的有效 PCM 波形一致，只减少 270ms 额外静音。

编辑器安装目录正在等待更新，独立宿主验证使用相同已安装版本的隔离副本完成，未修改正在使用的编辑器或更新进程。测试副本在验证后清理。
