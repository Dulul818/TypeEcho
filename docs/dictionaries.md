入口：练习页 `⋯ → 词库与导入…`，或命令面板 `TypeEcho: 词库与导入`。选库会开始一场新测试；取消选择后点击代码区继续。也可以先选库，再打开代码文件开始练习。

## 官网原生出词

选择词库后，选择官网模式和每局数量：

| 选项 | 官网行为 |
| --- | --- |
| shuffle（默认） | 每局打乱抽取；跨局可能重复，不保证整库只出现一次 |
| random | 由官网随机抽取，沿用官网的重复限制 |
| repeat | 按原顺序生成；下一局仍从原文开头开始，不是跨局接着学 |

单词每局 20 / 50 / 100 条；例句每局 1 / 3 / 5 句。使用官网 pipe 分隔，短语和整句作为完整条目参与抽取，句内词序保持不变。单词库固定逐词朗读；例句库可选按句或混合朗读。

首次选库或切换词库时，通过官网 **custom → change → open file** 的原生文件输入加载完整本地 TXT。同一个库只更改出词模式或数量时，直接修改官网表单选项，不重新导入。点击 Next / Repeat 使用官网按钮；插件不生成随机序列、不替换每局文本，也不改写官网存储。原先由插件分批推进的功能已按用户要求替换成官网规则。

官网也可以手动修改：**custom → change**，Mode 选择 shuffle / random / repeat，Limit 的 sections 填每局条目数。保留 **pipe**，不要切回 space，否则例句会拆成单词。

重开练习时，如果官网仍加载同一词库，就保留官网现有选项和测试；不会覆盖手工修改。旧测试版的分批选库会在首次重开时迁移为整库 + shuffle。普通“测试设置”仍可退出词库模式。

完整词庫保存在本机扩展目录，官网保留当前自定义文本；不随 Monkeytype 账号同步。没有覆盖命名 Saved Texts。JSON 中的中文翻译不送入官网或 TTS。

只预生成官网当前已生成的本局文本及附近词，不预生成整个词库；超过官网初始生成窗口的未来内容随着输入逐步准备。原有输入保护、异步预生成和完整语音排队不变。

## 自己导入和导出

在“词库与导入”底部选择“导入本地 TXT / JSON”。TXT 单词以空白分隔；例句每行一句。JSON 支持字符串数组、TypeWords `word` / `sentences` 记录、`words` 数组或本插件的 `entries` 导出结构。短语词条使用 JSON 以保留条目边界。

导入仅接受当前能练习的英文内容，去重并提示跳过数量；原文件不修改。同名导入另存一份，不覆盖旧库。文件上限 20 MiB，最多 100,000 个源条目，单条英文例句最多 1,200 字符。

导出 TXT 用于其他打字软件；导出 JSON 保留翻译、关联词和来源信息，适合备份或迁移。选择保存路径不会更改原库。
